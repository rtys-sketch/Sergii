# 3D-макет приміщення «MA PIZZA / МАРКЕТ МА ПІЦА» для гри (Blender)

Макет у реальному масштабі. Стіни, прорізи, приміщення й висота взяті з плану БТІ групи нежитлових приміщень
№ 1106 (М 1:100). Обладнання й меблі розставлені за відео-обходом. Людей не моделювали.

![План з маршрутом камери](renders/PLAN_annotated.jpg)

## Що взято з плану БТІ

| Приміщення за планом | Площа | Розміри | У макеті |
|---|---|---|---|
| 1106-1 зал | 55,1 м² | 6,32 × 10,66 (3,04 + 0,26 + 3,02 по фасаду), колона посередині | Торговий зал, каса, стійка «MAMA», передня частина кухні |
| 1106-2 зал | 17,7 м² | 3,14 × 5,46, вікно на вуличний фасад, проріз у залі біля фасаду | Кухня |
| 1106-3 кімната | 5,3 м² | 1,89 × 2,74, вікно на північ, двері 0,90 з коридору | Кабінет-склад |
| 1106-4 санвузол | 1,8 м² | 1,38 × 1,66, раковина в куті, унітаз біля дальньої стіни | WC |
| Коридор | | ≈ 0,85 × 2,3 (між стіною 2,31 і санвузлом) | Службовий коридор |
| Висота | | H = 3,46 | Стеля по всьому приміщенню |

**Зміни відносно плану (за актуальним станом і відео):**
- Двері в прольоті **3,04** (2,74 у світлі) — тепер **вікно** на 3 секції.
- Вхід з вулиці **MA PIZZA** — у прольоті **3,02** (2,72 у світлі) біля правої стіни: ліва секція, двері, права
  секція, як на відео. Він на одній осі з основним проходом і північними дверима (проріз 3,00).

## Для гри

- Одиниці — метри, Z вгору в Blender (у `.glb` автоматично Y вгору). Початок координат — внутрішній кут правої (східної)
  стіни біля вуличного фасаду. +Y — до північних дверей.
- `PlayerStart_Street` (колекція `08_Game_Markers`) — старт гравця на вулиці перед входом MA PIZZA. Там же маркери зон
  з номерами приміщень БТІ (`Zone_Kitchen_1106-2`, `Zone_WC_1106-4` …).
- Усі двері — окремі об'єкти з початком координат на осі петель (`Door_Street_MA_PIZZA`, `Door_North_Market`,
  `Door_WC`, `Door_Office`): поворот навколо Z відчиняє/зачиняє їх.
- Колекції за зонами: `01_Architecture`, `02_Sales_Hall`, `03_CashDesk_PizzaCounter`, `04_Kitchen`, `05_Corridor_WC`,
  `06_Office_Storage`. Світло для рендеру — `07_Lights_Render` (у `.glb` не експортується; LED-лінії, неон, екрани
  і підсвітка холодильників — емісійні матеріали й експортуються).

## Перезібрати

```bash
pip install bpy pillow            # або запускати через встановлений Blender
python3 blender/build_store.py --out blender/ma_pizza_store.blend --glb blender/ma_pizza_store.glb --render blender/renders
python3 blender/annotate_plan.py
# або: blender -b -P blender/build_store.py -- --out blender/ma_pizza_store.blend --glb blender/ma_pizza_store.glb
```

## Точність і припущення

- Оболонка (стіни, прорізи, колона, простінок, висота) — за розмірами з плану БТІ. Де розміру на плані немає
  (товщини стін, положення вікна кабінету, ширина простінків), його виміряно по скану креслення з точністю ≈ ±5 см.
- Розстановка обладнання — з відео: розміри типових холодильників, гірок, стелажів, столів. Положення каси,
  печі та столів на кухні — найменш певні (на відео вони частково закриті людьми).
- Логотипи сторонніх брендів замінено нейтральними упаковками. Вивіски самого закладу збережено.
