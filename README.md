# Сергій проти всіх: Останній нерв колективу

Мобільна **HTML5 / PWA** arcade-гра для iPhone (і Android): кидай свайпом помідори, какашки й банки в Сергія,
ухиляйся від того, що він кидає у відповідь, і доведи «Терпіння Сергія» до нуля.

- **Phaser 3 + TypeScript + Vite**, весь рендер — WebGL canvas з урахуванням `devicePixelRatio` (без розмиття на Retina).
- **Обличчя Сергія — справжнє, 1:1 з фото.** Голову вирізано нейромережевою маскою (BiRefNet) без жодної генеративної перемальовки;
  анімації — лише зсув / поворот / масштаб / squash (photo-puppet). Тіло, предмети, фон — процедурна графіка.
- Звук і музика синтезуються через Web Audio (жодних аудіофайлів), запускаються після першого дотику (iOS).
- PWA: manifest, іконки, Service Worker (офлайн після першого завантаження), fullscreen, safe-area для Dynamic Island.
- Прогрес у `localStorage`: рекорди, відкриті раунди, секретний режим, звук/музика, складність.

## Що в грі

| | |
|---|---|
| 5 раундів | «Ще терплять» → «Сергій щось підозрює» → «Останній нерв» → «Всі вже тут» → «Сергій проти всіх» (RAGE у фіналі) |
| Секретний режим | «Сергій: не треба було» — нескінченний, відкривається після проходження |
| Предмети | помідор (∞), какашка, банка + бонуси: яйце, тапок, туалетний папір, тараня, торт, **золота какашка** (x10) |
| Сергій | ухиляється (нахил / присідання / крок убік), **ловить банки** («ПОГАНА ІДЕЯ.»), кидає назад, ходить за банкою, знаходить щит |
| Керування | свайп угору — кидок (сила свайпу = сила кидка); тап ліворуч/праворуч — ухилитися; тап по картці — вибрати предмет |

## Запуск

```bash
npm install
npm run dev        # http://localhost:5173 (з --host видно в локальній мережі — можна відкрити з телефона)
npm run build      # продакшн-збірка в dist/
npm run preview    # перевірка продакшн-збірки
```

`dist/` — повністю статичний сайт з відносними шляхами: працює з будь-якого хостингу / підпапки.

### Публікація (URL для iPhone)

- **GitHub Pages:** Settings → Pages → Source: *GitHub Actions*. Далі кожен push у `main` публікує гру
  (workflow `.github/workflows/pages.yml`) на `https://<user>.github.io/<repo>/`.
- **Vercel / Netlify / Cloudflare Pages:** імпортувати репозиторій; framework — Vite, build `npm run build`, output `dist`.

На iPhone: відкрити URL у Safari → «Поділитися» → «На Початковий екран» — гра запускається на весь екран як застосунок.

## Ассети

`tools/make_assets.py` — пайплайн: з оригінального фото (`tools/source/sergii.jpg`, не комітиться) робить
маску `rembg`/BiRefNet-portrait, вирізає голову (прибирає фон, футболку й руку з банкою) → `public/assets/sergii-head.webp`,
а також PWA-іконки в `public/icons/`.

## Структура

```
src/
  main.ts                 bootstrap, DPR/safe-area layout, PWA, блок жестів iOS
  core/                   layout, save, audio (Web Audio synth), textures/background (процедурна графіка)
  data/config.ts          предмети, раунди, репліки Сергія
  game/                   Sergii (photo-puppet), Stage (псевдо-3D + паралакс), Fx, Crowd, Speech
  scenes/                 Boot, Menu, Rounds, Endless, Game, Hud
  ui/                     Button, Modal
```
