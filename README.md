# Сергій проти всіх: Останній нерв колективу

🎮 **[Грати онлайн з телефона](https://rtys-sketch.github.io/Sergii/)** — публічне посилання, яке можна надіслати друзям.

Мобільна **HTML5 / PWA** arcade-гра для iPhone (і Android): кидай свайпом помідори, какашки й банки в Сергія,
ухиляйся від того, що він кидає у відповідь, і доведи «Терпіння Сергія» до нуля.

- **Phaser 3 + TypeScript + Vite**, весь рендер — WebGL canvas з урахуванням `devicePixelRatio` (без розмиття на Retina).
- **Обличчя Сергія змінює вираз.** Базову голову вирізано з фото маскою BiRefNet; задоволений і злий варіанти створено з цієї фотографії для ігрової міміки. Анімації голови — зсув / поворот / масштаб / squash (photo-puppet). Тіло, предмети, фон — процедурна графіка.
- Звук і музика синтезуються через Web Audio (жодних аудіофайлів), запускаються після першого дотику (iOS).
- PWA: manifest, іконки, Service Worker (офлайн після першого завантаження), fullscreen, safe-area для Dynamic Island.
- Прогрес у `localStorage`: рекорди, відкриті раунди, секретний режим, звук/музика, складність.

## Що в грі

| | |
|---|---|
| 5 раундів | «Ще терплять» → «Сергій щось підозрює» → «Останній нерв» → «Всі вже тут» → «Сергій проти всіх» (RAGE у фіналі) |
| Секретний режим | «Сергій: не треба було» — нескінченний, відкривається після проходження |
| Предмети | помідор (∞), какашка, банка + бонуси: яйце, тапок, туалетний папір, тараня, торт, **золота какашка** (x10) |
| Сергій | ухиляється (нахил / присідання / крок убік), **ловить банки** («ПОГАНА ІДЕЯ.»), кидає назад, ходить за банкою, знаходить щит |
| СИЛА ПУПКА | коли терпіння Сергія падає до 50%, він може зарядити спрямовану ударну хвилю; ухились ліворуч або праворуч від позначеної смуги |
| Міміка й репліки | Сергій задоволений після вдалих атак і промахів гравця, злиться після влучань та під час RAGE; серед реплік є «Іди на трасу», «Зараз голову об холодильник кину», «Вибий технічку, якщо хочеш жити», «За розвозки вб’ю», «Там ями, не поїду» |
| Події | «Розвозка приїхала» (поповнення запасів), «Сергію дзвонять» (влучання x2), «Технічка!» (ключ), «Холодильник!» (повільний, але великий), щит, тапок, «Пішов за банкою», «Перерва закінчилася»; червона стрічка підказує, що робити |
| Колекція фраз | кожна почута фраза Сергія зберігається й показується в «Рекордах» (5 фраз) |
| Після раунду | звання за стилем гри («Снайпер відділу», «Телефон протри»…) і цитата раунду від Сергія; ділитися — лише текст + посилання |
| Керування | свайп угору — кидок (сила свайпу = сила кидка); коли Сергій замахується — тап ліворуч/праворуч, щоб ухилитися; тап по картці — вибрати предмет |

### Темп і читабельність

Гра навмисно неквапна: репліки тримаються стільки, скільки треба, щоб їх прочитати (2.3–4.8 с), нова репліка
не перебиває щойно показану, а фірмові фрази Сергія з'являються в жовтій бульбашці з коротким сповільненням.
Події йдуть по черзі — стрічка → фраза → замах; Сергій рухається й ухиляється плавніше, атаки мають довший
замах, предмети летять повільніше, а камера зсувається лише тоді, коли в тебе справді щось летить.

## Запуск

```bash
npm install
npm run dev        # http://localhost:5173 (з --host видно в локальній мережі — можна відкрити з телефона)
npm run build      # продакшн-збірка в dist/
npm run preview    # перевірка продакшн-збірки
```

`dist/` — повністю статичний сайт з відносними шляхами: працює з будь-якого хостингу / підпапки.

### Публікація (URL для iPhone)

- **GitHub Pages:** [публічна гра](https://rtys-sketch.github.io/Sergii/) автоматично оновлюється після кожного push у `main`
  через workflow `.github/workflows/pages.yml`.
- **Vercel / Netlify / Cloudflare Pages:** імпортувати репозиторій; framework — Vite, build `npm run build`, output `dist`.

На iPhone: відкрити URL у Safari → «Поділитися» → «На Початковий екран» — гра запускається на весь екран як застосунок.

## Ассети

`tools/make_assets.py` — пайплайн: з оригінального фото (`tools/source/sergii.jpg`, не комітиться) робить
маску `rembg`/BiRefNet-portrait, вирізає голову (прибирає фон, футболку й руку з банкою) → `public/assets/sergii-head.webp`,
а також PWA-іконки в `public/icons/`.

`public/assets/sergii-head-happy.webp` і `public/assets/sergii-head-angry.webp` — похідні від базової голови ігрові варіанти міміки. Скрипт `make_assets.py` їх не перегенеровує.

## Структура

```
src/
  main.ts                 bootstrap, DPR/safe-area layout, PWA, блок жестів iOS
  core/                   layout, save, audio (Web Audio synth), textures/background (процедурна графіка)
  data/config.ts          предмети, раунди, репліки Сергія
  game/                   Sergii (photo-puppet), Stage (псевдо-3D + паралакс), Fx, Crowd, Speech
  scenes/                 Boot, Menu, Rounds, Endless, Game, Hud
  ui/                     Button, Modal
```
